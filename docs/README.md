# 文档

协议字段以约定为准。进度与状态以验收总表为准。课程设计以项目方案为准。

## 地图

| 文档 | 用途 |
|------|------|
| [`碎片档案_v1格式约定.md`](碎片档案_v1格式约定.md) | 协议：字段、端口、指令码（签字后字段只读） |
| [`碎片档案_项目方案.md`](碎片档案_项目方案.md) | 课程方案原文 |
| [`验收与进度.md`](验收与进度.md) | 验收核对表（编号、责任人、状态） |
| [`实验记录.md`](实验记录.md) | 实验 0–9 书面记录 |
| [`构建与演示.md`](构建与演示.md) | WSL 构建、关房四窗、主机登记、十五分钟讲解 |
| [`模块说明.md`](模块说明.md) | 对接、传块、界面与通告、案卷装载、房间内进度 |
| [`黑白盒测试.md`](黑白盒测试.md) | 黑盒两种方法、白盒六种覆盖、操作清单 |

源码旁的 `src/*/README.md`、`tests/README.md` 只说明该目录职责与命令，不重复协议正文。

演示可以走网页案情板：在 WSL 执行 `python3 ui_prototype/server.py`，浏览器打开 `http://localhost:8080/ui_prototype/index.html`。进房、下载仍由 `client_transfer` 完成。终端 `./client_transfer` 保留为联调入口。

## 规则

| 类别 | 说明 |
|------|------|
| GitHub | 只提交 markdown 等小文档 |
| 只读 | v1 约定的字段表、端口、错误码（签字后） |
| 可编辑 | 本 README、验收总表状态、实验记录补行 |

源码、成品案卷、pcap 不放在本目录。
